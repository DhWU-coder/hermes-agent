# 任务耗时实施方案

1. 新增独立任务计时模块：真实用户起点、后台续跑、终止时间、历史展示投影。
2. 接入网关现有消息开始、完成、异常路径及隔离计算进程的元数据镜像，复用会话所属数据库保存展示元数据。
3. 扩展 Python 协议并重新生成共享 TypeScript 类型。
4. 在 TUI 增加底部独立计时行和回复耗时页脚；恢复历史和切换会话时恢复或清空对应状态。
5. 验证异步接续、历史恢复、缺失时间戳、会话隔离、终止冻结以及窄屏和长标题展示；Python 测试使用 scripts/run_tests.sh。
6. 构建本地 TUI，检查改动与测试结果；不提交 Git、不创建分支，不主动终止用户运行中的会话。
7. 图形聊天页复用网关 `task_timing`；旧历史缺少计时元数据时，仅按有效的用户消息和回复时间戳标“约”估算。运行、后台等待和完成状态分别显示，并测试切换与刷新后的恢复。
