# Hermes 网页图形聊天页实施方案

1. 在 Dashboard 路由和侧边导航注册 `/chat-ui`，独立懒加载页面，并保留 `/chat`。
2. 建立图形聊天的连接与会话状态模块，接入共享 JSON-RPC 客户端和现有 REST 列表/历史接口；明确存储 ID 与运行时 ID 的映射及 profile 作用域。
3. 实现会话列表、消息区、流式状态、底部输入与文件上传；新会话创建和旧会话激活都不关闭其他运行中的会话。
4. 接通停止、工具授权及其他服务端请求，处理断线重连、页面刷新和异常展示。
5. 添加针对并发会话隔离、切换、重连和发送行为的测试；执行 Dashboard 类型检查、测试、代码检查与构建，并验证页面交互。
