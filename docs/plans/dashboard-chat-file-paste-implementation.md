# 网页聊天文件粘贴实施方案

1. 在 Dashboard 文件路由加入 profile 作用域内的普通文件流式上传端点，复用现有分块写入及大小限制。
2. 在浏览器端复用 DataTransfer 提取和去重，保留图片附件分支；新增普通文件上传及 `@file:` 引用格式化。
3. 聊天页接入粘贴、拖入、文件选择入口及失败提示，文件引用进入原 Ink TUI 输入框。
4. 加入行为测试，运行 Python 路由测试、网页 Vitest、类型检查和必要构建。

## 完成情况

- 上传路由使用现有认证、profile 作用域、100 MB 流式上限与失败临时文件清理。
- 浏览器原生粘贴事件负责读取文件对象；只取得文件名时保留文字并提示使用选文件入口。
- 后端文件路由测试、网页相关测试、TypeScript 类型检查、ESLint 与生产构建通过。现有 Dashboard 进程需要重启，才能加载新增后端路由。
